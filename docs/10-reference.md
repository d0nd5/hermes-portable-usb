# 10 - Reference

## USB Directory Layout (Complete)

```
USB_ROOT/
|
|-- hermes-usb-build.ps1            Windows builder (run once)
|-- hermes-usb-build.sh             Linux builder (run once)
|-- launch-windows.ps1              Windows daily launcher
|-- launch-linux.sh                 Linux daily launcher
|-- README.txt                      Quick reference (generated by builder)
|
|-- hermes-portable/
|   |
|   |-- hermes-agent/               NousResearch hermes-agent git clone
|   |   |-- venv/                   Python 3.11 virtualenv (all Python deps)
|   |   |   |-- Scripts/            Windows: hermes.exe here
|   |   |   `-- bin/                Linux: hermes binary here
|   |   |-- scripts/                Official install/update/doctor scripts
|   |   |-- hermes/                 Hermes Python package source
|   |   |-- website/                Documentation source
|   |   `-- .git/                   Git repo (enables hermes update)
|   |
|   |-- git/                        PortableGit (Windows only, if no system Git)
|   |   |-- bin/                    git.exe, bash.exe
|   |   `-- ...
|   |
|   |-- data/
|   |   |-- .env                    API keys and provider config (ENCRYPT DRIVE)
|   |   |-- sessions/               SQLite DBs of conversation history
|   |   |-- memory/                 Agent long-term memory store
|   |   `-- skills/                 Custom skill definitions (.yaml)
|   |
|   `-- logs/
|       |-- launcher.log            Launcher stdout/stderr
|       `-- gateway.log             Gateway process log
|
`-- hermes.vc                       VeraCrypt container (optional, recommended)
```

## Environment Variables

| Variable | Set By | Purpose |
|----------|--------|---------|
| `HERMES_HOME` | Launcher | Root of Hermes portable install on USB |
| `HERMES_DATA` | Launcher | Data directory (sessions, memory, .env) |
| `HERMES_GIT_BASH_PATH` | Windows installer | Path to PortableGit bash.exe |
| `HERMES_DISABLE_WINDOWS_UTF8` | Manual | Set to `1` to fall back to cp1252 stdio on Windows |
| `TMPDIR` | Manual (if needed) | Override tmp dir if /tmp is too small |
| `HTTP_PROXY` / `HTTPS_PROXY` | Manual (if needed) | Proxy settings for API calls |

## Full Command Reference

```
hermes                          Open interactive TUI
hermes chat                     Alias for interactive TUI

hermes model                    Interactive provider/model selector

hermes config migrate           Migrate config after version update
hermes gateway                  Show gateway status

hermes gateway start            Start gateway in background
hermes gateway stop             Stop gateway

hermes skills                   List loaded skills
```

## Launcher Quick Reference

### Windows

```powershell
# Interactive chat
powershell -ExecutionPolicy Bypass -File E:\launch-windows.ps1

# With hermes subcommand
powershell -ExecutionPolicy Bypass -File E:\launch-windows.ps1 model
powershell -ExecutionPolicy Bypass -File E:\launch-windows.ps1 doctor
powershell -ExecutionPolicy Bypass -File E:\launch-windows.ps1 gateway start
powershell -ExecutionPolicy Bypass -File E:\launch-windows.ps1 update

# Short alias (run from E:\ in PowerShell)
Set-Alias h "powershell -ExecutionPolicy Bypass -File E:\launch-windows.ps1"
```

### Linux

```bash
# Interactive chat
./launch-linux.sh

# With subcommand
./launch-linux.sh model
./launch-linux.sh doctor
./launch-linux.sh gateway start
./launch-linux.sh update

# Add to ~/.bashrc for convenience (adjust path)
alias hermes-usb='/media/$USER/HERMESUSB/launch-linux.sh'
```

## Messaging Gateway Platforms

| Platform | Setup Requirement | Notes |
|----------|-----------------|-------|
